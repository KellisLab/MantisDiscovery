# MantisDiscovery

The Mantis Discovery website, published at https://kellislab.github.io/MantisDiscovery/. Its source is in
[`website/`](website/), and [`website/README.md`](website/README.md) explains how to run and change it.

GitHub Pages serves the site from the root of `main`. Apart from this README, the license, `.github/` and
`website/`, the files at the root are the built site. The publish workflow (`.github/workflows/pages.yml`)
rewrites them whenever `website/` changes, so don't edit them by hand.
