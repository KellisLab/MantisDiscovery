Mantis

Mantis puts the papers, code and data behind a project into one shared space, where AI agents work with our researchers. The agents search the literature and run computations. The researchers check what the agents produce and choose which ideas to pursue.

Walkthrough

Our approach

Each project has its own space in Mantis. Everything we write or compute for a project is saved there as a record, which we can search and cite later.

  1. 01

    Geometric reasoning

    Mantis represents each record as a point in a space with thousands of dimensions and draws the points as a map, so records that say similar things sit close together. We search the map and outline regions of it to compare the records inside.

    We can see a project’s whole history at once. Related attempts end up near each other, so it is easy to notice when an idea has been tried before.

  2. 02

    Traceability

    Failed attempts stay in the project along with the fixes that followed them. Each record points to the file and lines it came from and stores a hash of that source, and it carries a status such as withdrawn or independently verified.

    Anyone can follow how we reached a result, including the approaches that did not work.

  3. 03

    Audits

    Before a claim goes into a paper, we check it against the records behind it. For our Hadwiger paper, an audit found that an early draft used an inequality in the wrong direction. Later rewrites brought the claimed gap down from eight to two, and the flawed draft is still in the project.

    Mistakes can be caught before a paper is published, and each correction is filed next to the mistake it fixed.

  4. 04

    Certificates

    Some proofs come down to a long but finite list of cases. For those, a program checks every case and saves the result as a certificate, and we test the checker on a deliberately broken input to make sure it fails.

    Readers can run the check themselves.
